흑월 조직 포털 — 서버/데이터베이스 버전
======================================

포함 기능
- Express 서버 + SQLite 데이터베이스
- 서버 측 비밀번호 해시(scrypt), HttpOnly 세션 쿠키
- 기본 관리자 계정 생성: admin / admin0000
- 관리자만 조직원 계정 생성 가능
- 누구나 지원서를 제출할 수 있지만, 지원서 열람/상태 변경 API는 관리자만 접근 가능
- 지원서 상태: 접수, 검토 중, 승인, 거절
- 로그인한 조직원은 장부 항목을 데이터베이스에 저장 가능
- 로그인 시도 제한, 기본 보안 헤더

로컬 실행
1. Node.js 20 이상 설치
2. 프로젝트 폴더에서 `npm install`
3. `npm start`
4. 브라우저에서 http://localhost:3000 접속


보안 중요사항
- 공개 배포 전 ADMIN_PASSWORD 환경변수를 강력하고 고유한 비밀번호로 설정하세요.
- 최초 실행 때 관리자 계정이 생성됩니다. 이미 DB에 admin 계정이 만들어진 후 환경변수만 바꿔도 기존 계정 비밀번호는 자동 변경되지 않습니다.
- 실제 공개 서비스에서는 기본 비밀번호를 반드시 바꾸고 HTTPS를 사용하세요.
- SQLite 파일은 `data/heukwol.sqlite`에 저장됩니다. 배포 호스트에서 영구 디스크를 연결해야 재시작/재배포 뒤 데이터가 유지됩니다.
- 지원서에는 연락처 등 개인정보가 포함될 수 있으니 접근 권한과 보관/삭제 정책을 운영자가 정해야 합니다.

Render 배포
1. 이 폴더를 GitHub 저장소에 올립니다.
2. Render에서 New + > Blueprint로 저장소를 연결하고 `render.yaml`을 선택합니다.
3. Render 환경변수 `ADMIN_PASSWORD`에 강력한 비밀번호를 입력합니다.
4. 영구 디스크가 연결되었는지 확인하고 배포합니다.

API 권한
- POST /api/apply: 공개 지원서 제출
- GET /api/applications: 관리자 전용
- PATCH /api/applications/:id/status: 관리자 전용
- POST /api/staff: 관리자 전용
- GET/POST /api/ledger: 로그인 조직원 전용

참고
지원서 페이지의 HTML만 따로 정적 호스팅하면 서버 API가 작동하지 않습니다. 반드시 이 Node 서버를 함께 배포해야 합니다.
